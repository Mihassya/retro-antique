# Ретро — сайт антикварной лавки

Сайт антикварного магазина «Ретро» в Усть-Каменогорске (ул. Казахстан, 77, работает с 2006 года).
Главная оформлена как сервант: дверцы открываются сами, на стеклянных полках стоят вещи с бумажными
бирками. Монеты и банкноты лежат в альбомах, как у коллекционеров.

## Что есть

- **Сервант** на первом экране: стеклянные дверцы разъезжаются после загрузки фото, клик по стеклу
  закрывает и открывает их. Прокрутку ничто не держит.
- **Полки**: по три вещи «на витрину» в каждой категории. Высота предмета считается из реальных
  сантиметров, поэтому вещи стоят в пропорции друг к другу и не ломают ряд.
- **Каталог** с фильтрами по категории, бюджету, сортировкой и проданными вещами. Фильтры хранятся
  в адресе страницы — подборкой можно поделиться ссылкой.
- **Альбом монет**: страницы перелистываются через корешок (3D, Web Animations API), монета
  наклоняется к курсору и ловит блик, нажатая — выходит из ячейки и переворачивается.
- **Альбом банкнот**: банкноты в прозрачных кармашках выглядывают при наведении и достаются целиком.
- **«Из другого города»**: форма без бэкенда собирает первое сообщение и открывает WhatsApp —
  лавка работает через переписку.
- `prefers-reduced-motion`, работа с клавиатуры, панель деталей на телефоне — шторка снизу.

## Стек

React 19, TypeScript (strict), Vite, Tailwind CSS v4, React Router 7. Без библиотек анимации:
CSS transitions и Web Animations API.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. На Vercel все пути отдаются в `index.html` (`vercel.json`).

## Структура

```
src/
  data/          товары, монеты, банкноты, контакты; компоненты читают их только через data/index.ts
  components/    сервант, полки, шапка, форма, общие кнопки
  features/
    catalog/     фильтры и сортировка (чистые функции, состояние в URL)
    album/       альбомы монет и банкнот, панель деталей, наклон монеты
  pages/         главная, каталог, монеты, банкноты
```

Данные сейчас лежат в типизированных файлах `src/data/`. Позже их заменит источник, который
наполняет сам владелец (планируется Telegram-бот), — интерфейс при этом не меняется.
