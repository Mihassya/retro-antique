# Ретро — сайт антикварной лавки

Сайт антикварного магазина «Ретро» в Усть-Каменогорске (ул. Казахстан, 77, работает с 2006 года).
Главная оформлена как сервант: дверцы открываются сами, на стеклянных полках стоят вещи с бумажными
бирками. Монеты и банкноты лежат в альбомах, как у коллекционеров.

## Что есть

- **Сервант** на первом экране: стеклянные дверцы разъезжаются после загрузки фото, клик по стеклу
  закрывает и открывает их. Прокрутку ничто не держит.
- **Полки**: по три вещи «на витрину» в каждой категории. Высота предмета считается из реальных
  сантиметров, поэтому вещи стоят в пропорции друг к другу и не ломают ряд.
- **Каталог** с фильтрами по категории, бюджету, сортировкой и проданными вещами. Фильтры хранятся
  в адресе страницы — подборкой можно поделиться ссылкой.
- **Альбом монет**: страницы перелистываются через корешок (3D, Web Animations API), монета
  наклоняется к курсору и ловит блик, нажатая — выходит из ячейки и переворачивается.
- **Альбом банкнот**: банкноты в прозрачных кармашках выглядывают при наведении и достаются целиком.
- **«Из другого города»**: форма без бэкенда собирает первое сообщение и открывает WhatsApp —
  лавка работает через переписку.
- `prefers-reduced-motion`, работа с клавиатуры, панель деталей на телефоне — шторка снизу.
- **Админка `/admin`** для владельца, удобная с телефона: снять вещь камерой, указать название
  и цену (описание по желанию) — фон с фото убирается прямо в браузере, вещь сразу на сайте.
  Правка цены, «продано», удаление. Отдельный раздел **«Витрина»**: что стоит на полках серванта,
  до трёх вещей на раздел, порядок стрелками.

## Стек

React 19, TypeScript (strict), Vite, Tailwind CSS v4, React Router 7. Без библиотек анимации:
CSS transitions и Web Animations API. Товары — Supabase (Postgres + Storage + Auth), удаление фона —
[@imgly/background-removal](https://github.com/imgly/background-removal-js) (модель работает в браузере,
лицензия AGPL-3.0).

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. На Vercel все пути отдаются в `index.html` (`vercel.json`).

## Структура

```
src/
  data/          товары, монеты, банкноты, контакты; компоненты читают их только через data/index.ts
  components/    сервант, полки, шапка, форма, общие кнопки
  features/
    catalog/     фильтры и сортировка (чистые функции, состояние в URL)
    album/       альбомы монет и банкнот, панель деталей, наклон монеты
  pages/         главная, каталог, монеты, банкноты
```

```
src/
  admin/         админка: вход, список вещей, форма с фото, витрина; отдельный чанк
  lib/backend/   где живут товары: Supabase или демо в localStorage браузера
supabase/        schema.sql (таблица, права, хранилище фото) и seed.sql (образцы)
api/keepalive.ts ежедневный запрос к базе по Vercel Cron, чтобы бесплатный проект не засыпал
```

Монеты, банкноты и контакты лежат в `src/data/`. Товары сайт загружает из Supabase при открытии
страницы, поэтому изменения из админки видны сразу, без пересборки.

## Админка и база

Без ключей Supabase сайт и `/admin` работают в **демо-режиме**: данные — образцы из
`src/data/items.ts`, правки хранятся только в этом браузере, войти можно с любым паролем.

Подключение (один раз):

1. Создать проект на [supabase.com](https://supabase.com) (бесплатный тариф: 500 МБ базы, 1 ГБ фото).
2. SQL Editor → выполнить `supabase/schema.sql`, затем, если нужны образцы, `supabase/seed.sql`.
3. Authentication → Sign In / Providers → выключить **Allow new users to sign up**.
   Authentication → Users → **Add user**: почта и пароль владельца.
4. SQL Editor: `insert into public.admins (email) values ('почта-владельца');` — без этого вход
   пройдёт, но сохранять база не даст.
5. Settings → API: скопировать Project URL и anon key в `.env.local` (образец — `.env.example`)
   и в Vercel → Settings → Environment Variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`),
   затем передеплоить.

Права проверяет сама база (RLS): читать товары может любой, менять — только вошедший пользователь
из таблицы `admins`. Ключ anon публичный по замыслу и попадает в сборку — это нормально.
